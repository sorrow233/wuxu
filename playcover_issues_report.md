# PlayCover Issues Deep Report

## ⚠️ Arknights Custom Analysis (Metal Validation Crash)
- **Root Cause**: `MTLTextureDescriptor` validation failure. Likely invalid resolution or incompatible device model.
- **Workaround**: Set fixed resolution (e.g. 1080p), disable 'Force aspect ratio', and try 'iPad Pro M2' model.
